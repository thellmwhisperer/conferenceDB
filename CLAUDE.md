# ConferenceDB

Read these files before doing anything:

1. `AGENTS.md` — operational contract (pipeline, dependencies, workflow)
2. `docs/semantic_layer.md` — database semantic layer (schema, query patterns, answer formatting)

Run all Python scripts with `.venv/bin/python` (scripts live in `src/`).
Run tests with `.venv/bin/python -m pytest tests/ -v`.
